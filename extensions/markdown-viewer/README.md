# Markdown viewer

Read local Markdown with text-based Mermaid diagrams without uploading the file.

Click a local `.md` link in a Markdown chat reply, then choose the file in the browser picker. The link only supplies a filename hint. You can also use **Open Markdown file…** in the command palette. The viewer accepts `.md` files up to 512 KB.

The viewer treats links and HTML as non-interactive and does not load images. It draws supported Mermaid diagrams as text and shows source for diagrams it cannot draw. Closing the viewer discards the document.
