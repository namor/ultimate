Automatic Plan returns one advisory plan from a protected fork before substantive coordinator work.

Open **Automatic Plan** from the command palette and link a model family for this project. A Plan family with Astra at low effort is a starting point. New plans use that family’s current model and effort, including changes from presets. Existing threads keep their original choice. Off is independent of model presets. The coordinator model and independent final reviewer stay unchanged.

The first call sends bounded text from recent task and user inputs. It does not send the full transcript, tool output, images, memory or system prompt. The fork retains history locally, but ordinary inputs, Continue, Compact, configuration and descendants cannot run there. The planner has no tools or coordinator permissions.

**Continue planning** reopens the same thread. A follow-up sends your text and the most recent plan to the selected provider. It does not notify the coordinator. **Send revised plan** copies the displayed revision back as advice without starting a model call or giving permission to act.
