Plan and Review ask one configured advisory model for bounded advice on a coordinator branch, without giving that model tools or creating a chat it can run.

The composer’s Plan & Review menu has independent automatic switches and manual buttons. Assign both modes together in **Model families → Plan and Review**. A request uses the selected Codex model and effort, or fails without substitution. The normal coordinator model is unchanged.

The coordinator requests Plan once before substantive implementation and Review for a named commit before delivery. Review reads a bounded diff against the target branch’s merge base. The receipt says if that diff was cut short or if the commit changed. Apply and verify suggestions in the coordinator conversation. Neither mode provides approval, implements changes, or replaces independent final review.

Each request sends at most 12,000 bytes of source packet, plus fixed instructions. Codex does not enforce the requested output cap. The card shows the requested effort and reported usage, not a provider attestation of reasoning effort or subscription cost. A restart can recover a saved response. If a request may have been sent but no response was saved, the system does not send it again automatically.
